# Security policy

Report a vulnerability privately, not in a public issue. Use
[Report a vulnerability](https://github.com/raeva-io/raeva/security/advisories/new)
on GitHub, or email hello@raeva.io with "security" in the subject.

Include the raeva version (`raeva --version`), the command, and the smallest
project or input that shows the problem.

Only the latest release gets security fixes.
