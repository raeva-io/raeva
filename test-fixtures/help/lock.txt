Inspect, compare or verify raeva.lock

Usage: raeva lock [OPTIONS] <COMMAND>

Commands:
  verify  Check that the store holds every locked artifact with its pinned checksum
  info    Show lockfile metadata and statistics
  diff    Compare two lockfiles without resolving or downloading
  help    Print this message or the help of the given subcommand(s)

Options:
  -h, --help
          Print help (see a summary with '-h')

Global Options:
  -C, --project-root <PATH>
          The project directory, which holds the root pom.xml
          
          [default: .]

  -v, --verbose...
          Show more output for debugging (repeatable; set RUST_LOG to override verbosity entirely)

  -q, --quiet
          Show only essential output (no spinners or progress bars)

      --json
          Produce machine-readable JSON output (implies --quiet)

      --offline
          Use cached data and file repositories only; commands that need the network fail

  -s, --settings <FILE>
          Read this Maven settings file instead of ~/.m2/settings.xml, as mvn -s does

  -P, --activate-profiles <IDS>
          Activate Maven profiles, or deactivate one written !id, as mvn -P does (repeatable)

  -D, --define <NAME=VALUE>
          Set a Maven user property, as mvn -D does (repeatable)

Examples:
  raeva lock verify                   # Check the store against every pin
  raeva lock diff old.lock            # Compare old.lock with raeva.lock
  raeva lock info                     # Show the schema, platforms and package counts
