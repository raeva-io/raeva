Generate a software bill of materials from raeva.lock

Usage: raeva sbom [OPTIONS]

Options:
      --module <MODULE>
          Select a module by root-relative pom.xml path or unique groupId:artifactId

      --platform <OS-ARCH>
          Report only this recorded platform (default: all platforms)

      --jdk <VERSION>
          Report only this exact recorded target JDK (default: all JDKs)

  -o, --output <FILE>
          Write the SBOM to a file instead of stdout

      --vex <FILE>
          Add the analyses an OpenVEX file records (repeatable)

  -h, --help
          Print help (see a summary with '-h')

Global Options:
  -C, --project-root <PATH>
          The project directory, which holds the root pom.xml
          
          [default: .]

  -v, --verbose...
          Show more output for debugging (repeatable; set RUST_LOG to override verbosity entirely)

  -q, --quiet
          Show only essential output (no spinners or progress bars)

      --json
          Produce machine-readable JSON output (implies --quiet)

      --offline
          Use cached data and file repositories only; commands that need the network fail

  -s, --settings <FILE>
          Read this Maven settings file instead of ~/.m2/settings.xml, as mvn -s does

  -P, --activate-profiles <IDS>
          Activate Maven profiles, or deactivate one written !id, as mvn -P does (repeatable)

  -D, --define <NAME=VALUE>
          Set a Maven user property, as mvn -D does (repeatable)

Output:
  Writes a CycloneDX 1.5 JSON document to stdout unless -o/--output is
  provided. By default, it covers all recorded platforms and JDKs when
  their selected module graphs and evidence agree. Otherwise, select a
  target with --platform and --jdk.

  --vex adds the statements an OpenVEX file makes about the selected
  modules' dependencies as vulnerabilities with an analysis. It does not
  query OSV. Analyses combine all selected modules: an affected module
  takes precedence, and a missing assessment keeps the result in triage.

Examples:
  raeva sbom
  raeva sbom --platform linux-x86_64 --jdk 21
  raeva sbom --module app/pom.xml
  raeva sbom --module com.acme:app
  raeva sbom -o bom.json
  raeva sbom --module app/pom.xml --vex vex.json
