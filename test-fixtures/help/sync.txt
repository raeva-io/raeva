Resolve dependencies, download artifacts, and update raeva.lock

Usage: raeva sync [OPTIONS]

Options:
  -f, --frozen
          Fail if raeva.lock would change, using the locked SNAPSHOT builds (CI mode)

  -u, --update
          Re-resolve all dependencies, taking newer SNAPSHOT builds, and update raeva.lock

      --platforms <OS-ARCH>
          Resolve these os-arch pairs instead of the ones raeva.lock records, keeping other recorded platforms that still match (e.g., linux-x86_64,macos-aarch64)

      --allow-missing-checksums
          Accept files that have no server-published checksum sidecar and that raeva.lock does not pin (SUPPLY-CHAIN RISK: a hostile or misconfigured mirror could serve unverified bytes; off by default)

  -h, --help
          Print help (see a summary with '-h')

Global Options:
  -C, --project-root <PATH>
          The project directory, which holds the root pom.xml
          
          [default: .]

  -v, --verbose...
          Show more output for debugging (repeatable; set RUST_LOG to override verbosity entirely)

  -q, --quiet
          Show only essential output (no spinners or progress bars)

      --json
          Produce machine-readable JSON output (implies --quiet)

      --offline
          Use cached data and file repositories only; commands that need the network fail

  -s, --settings <FILE>
          Read this Maven settings file instead of ~/.m2/settings.xml, as mvn -s does

  -P, --activate-profiles <IDS>
          Activate Maven profiles, or deactivate one written !id, as mvn -P does (repeatable)

  -D, --define <NAME=VALUE>
          Set a Maven user property, as mvn -D does (repeatable)

Examples:
  raeva sync                          # Resolve and lock dependencies
  raeva sync --frozen                 # CI mode: fail if lockfile would change
  raeva sync --update                 # Force fresh resolution
  raeva sync --offline                # Use cached data and file repositories
  raeva sync --platforms linux-x86_64,macos-aarch64
