# Dependency graphs where Maven 3.10 (maven-resolver 2, breadth-first
# collection) and Maven 3.9 (maven-resolver 1.9, depth-first) may differ.
# Maven 3.9 with its breadth-first collector gives the 3.10 result unless an
# `expect 3.9-bf` line says otherwise.
# differential.py checks the expect lines against real Maven; the Rust tests
# in rv-resolver/src/solver/tests/modes.rs check raeva in each mode.

## range-winner-skipped
# A hard range beats the nearer soft version, but breadth-first collection
# read the soft version first and skipped the range's subtree.

x:2 > new:1
old:1
new:1
expect 3.9: a:1 b:1 new:1 x:2
expect 3.10: a:1 b:1 x:2
